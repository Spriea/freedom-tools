核心原则：本 App 不采集任何用户个人数据。

本 App 不要求注册账号、不收集身份信息、不追踪用户行为，也不接入任何第三方分析或广告 SDK。

3本地存储

以下信息仅保存在你的设备本地，不会上传到我们的服务器；我们不运营用于收集这些信息的服务器：

  • 首次安装时间戳：用于计算 30 天免费试用剩余天数。该时间戳使用 ChaCha20-Poly1305 算法加密后保存在 iOS Keychain。普通卸载并重新安装 App 不会重置该时间戳；即使有人导出 Keychain 数据，也无法直接读取明文。
  • 购买状态：用于保存你是否已完成 Pro 解锁购买。购买记录与 Apple ID 绑定，并由 Apple StoreKit 管理。
  • 主题选择、语言选择和倒计时标签：保存在 UserDefaults 中。这些内容为明文，但不包含敏感信息。

4网络请求说明

本 App 仅在你主动使用“服务器校时”功能时发起网络请求，并遵循以下规则：

  • 默认不发起请求：默认使用设备本地时间，完全不联网。
  • 仅向用户指定的网址发起请求：当你在“设置 → 时间同步”中选择电商平台（如淘宝、京东、Amazon 等）或填写自定义 HTTPS URL 后，App 才会向该 URL 发送一次 HEAD 或 GET 请求。
  • 请求中不携带用户数据：不发送 Cookie，不发送除标准 User-Agent 之外的标识信息，也不发送请求正文。
  • 仅读取响应头：App 只解析 HTTP 响应中的 Date 头，不读取响应正文，也不抓取商品页面内容。
  • 绕过缓存：请求 URL 会附加随机查询参数 _t=时间戳，且 URLSession 配置为 urlCache = nil。
  • 失败时静默降级：任何网络错误都会静默回退到设备本地时间，不影响正常使用。

请求示例：

HEAD https://www.taobao.com/?_t=1719500000 HTTP/1.1
User-Agent: FloatingClockPro/1.0 iOS/18.0
Accept: */*

App 仅读取响应中的 Date 字段：

Date: Wed, 30 Jul 2026 12:34:56 GMT

3Local Storage

The following information is stored only on your device and is not uploaded to our servers. We do not operate a server for collecting this information:

  • First-install timestamp: Used to calculate the remaining days of the 30-day free trial. The timestamp is encrypted using ChaCha20-Poly1305 and stored in the iOS Keychain. Ordinarily uninstalling and reinstalling the app does not reset it. Exported Keychain data does not reveal the plaintext value directly.
  • Purchase state: Records whether Pro has been unlocked. Purchase records are tied to your Apple ID and managed by Apple StoreKit.
  • Theme, language, and countdown labels: Stored in UserDefaults. They are stored in plaintext but do not contain sensitive information.

4Network Requests

The app only makes a network request when you actively use the “Server Time Sync” feature:

  • No requests by default: The app uses the device’s local time and does not access the network by default.
  • Only to URLs you specify: After you choose an e-commerce platform or enter a custom HTTPS URL in Settings → Time Sync, the app sends one HEAD or GET request to that URL.
  • No user data is sent: The request contains no cookies, no identifiers other than a standard User-Agent, and no request body.
  • Only response headers are read: The app parses only the HTTP Date header. It does not read response bodies or scrape product pages.
  • Cache bypass: A random query parameter _t=timestamp is appended and urlCache = nil is configured.
  • Silent fallback: Any network error silently falls back to the device’s local time.

Example request:

HEAD https://www.taobao.com/?_t=1719500000 HTTP/1.1
User-Agent: FloatingClockPro/1.0 iOS/18.0
Accept: */*

Only the Date header is read:

Date: Wed, 30 Jul 2026 12:34:56 GMT
